破天肉鸽 · 完整版
================

【正确打开方式】
1. 解压整个文件夹
2. 双击 start.bat
3. 浏览器自动打开后即可玩
4. 黑窗口要一直开着；关掉 = 网页打不开

【不要这样做】
- 不要直接双击 index.html（会报网页错误 / 加载失败）
- 不要只复制单个 html 文件

【如果还是网页错误】
1. 看黑窗口有没有报错；把完整报错发给作者
2. 若提示无法启动端口：关掉占用 5173 的程序，或重启电脑后再试
3. 杀毒软件拦截时：允许 PowerShell / 本地网络
4. 用 Edge 或 Chrome 打开

【改配表】
见 配表\使用说明.txt
编辑 Excel → convert.bat → 复制 json 到 data\ → 刷新重开
