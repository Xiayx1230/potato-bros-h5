# 破天肉鸽 · 公式幸存者

类幸存者（Roguelike Survivor）H5 小游戏。纯静态网页，支持手机浏览器。

**策划案：** [`破天肉鸽_H5策划案.md`](./破天肉鸽_H5策划案.md) · [`破天肉鸽构筑设计.md`](./破天肉鸽构筑设计.md) · [`技能体系策划案.md`](./技能体系策划案.md)

## 在线游玩

部署到 GitHub Pages 后，地址一般为：

`https://<你的用户名>.github.io/<仓库名>/`

## 本地运行

本项目为纯静态页面（ES Module，不能直接用 `file://`）：

```bash
# Python
python -m http.server 5173

# 或双击 start.bat / 开始游戏.bat
```

浏览器访问：http://127.0.0.1:5173/

## 操作

- **电脑**：WASD / 方向键移动
- **手机**：右下角虚拟摇杆；升级三选一直接点选
- 普攻与技能自动释放；吃经验球升级 → 三选一强化

### 用 Excel 配置

全部在 **`配表/`** 文件夹（详见 `配表/使用说明.txt`）：

1. 打开 `配表/`，首次双击 `init_excel.bat`
2. 改 `配表/excel_src/` 里某个 xlsx
3. 双击 `配表/convert.bat`
4. 把 `配表/json_out/` 里改过的 JSON **手动复制**到 `data/`
5. 网页 Ctrl+F5，重新开局

## 战斗公式（摘要）

```
期望总伤害 = 基础伤害 × 技能倍率 × 总暴击效果期望 × 总增伤减伤效果 × 最终命中 × 格挡减伤期望 × 攻速
基础伤害   = 攻击 × (1 − 防×4 / (攻 + 防×4))
最终命中   = 命中率 − 闪避率
格挡期望   = 格挡率×(1−格挡值) + (1−格挡率)×1
总战力     = 生命值战力 + 攻击战力 + 防御战力
```

暴击为圆桌互斥（高倍优先）：6倍天运 → … → 幸运 → 卓越 → 不暴击。  
增减伤为乘区相乘：伤害率、物理/元素（二选一）、PVP/PVE（二选一）、技能增伤。

实现见 `js/formula.js`。
